# Toolbar power connections — 9 November 2026

Power connections now belong to Equipable → Placeables and can occupy any of the eight saved toolbar slots. Select the connector slot and press B. The first machine click selects a temporary anchor without moving or reserving stock. A live green/red wire preview follows the target cell and snaps to a target machine's terminal. The second valid machine click submits one active-slot command; the worker rechecks both live IDs, cable length, reach, topology, research and stock before consuming one connector.

Clicking the first cell again clears the attempt without submitting a command or spending stock; build mode stays ready for a fresh anchor. Build exit, cancel, UI/input loss, slot changes (including another connector slot), world-generation changes and anchor removal also clear the draft. Draft anchors never enter a gameplay save. The first click requires 2 m reach; completion allows reach to either endpoint, so walking between clicks is supported. Cable length remains 12 m and the connector's cost/value is unchanged.

Preview and completed wires share quarter-turn-aware terminal geometry. Picking a machine resolves its own cell rather than the ground cell behind its upper geometry. Factory inspection retains power statistics, existing edges and disconnection controls; it directs new edge creation to the toolbar. Hidden inaccessible help reservations keep toolbar slots anchored as build instructions change, including at mobile width.
