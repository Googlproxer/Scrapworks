# Toolbar and placement feedback follow-up

Implemented and locally verified on 9 November following the user's 8 November 2026 feedback on the initial M6 UI. All six additional feedback criteria in the [updated plan](../../../../plans/milestone-06-first-working-machines.md) pass. The [initial report](../README.md) retains its original evidence.

Equipable is split into Tools and Placeables. The prybar remains equipped separately. Seven machine kinds can be assigned from Inventory & Crafting to eight saved toolbar slots; assignments reference the bag, never hold/reserve stock and remain when stock is depleted. Number keys 1–8, controller left/right and native toolbar buttons select the active slot. B/Select toggles world building, R/right shoulder rotates and click/south button places the selected silhouette. The worker resolves the active slot in command order and preflights normal unlock/stock/placement checks before consuming an item. Factory keeps its machine list, inspection, local transfers, wiring and existing power statistics. Coordinate entry is removed; live graphs remain future work.

The previous B path still selected the legacy two-cell developer test building. Factory controls also used a 2 m centre-distance test while the placement debug ring showed 3 m, and overlap rejected the whole cell rather than the actual 1.2 m machine body. Production building now uses the selected one-cell placeable. Reach is 2 m to the nearest footprint point, including corners, and local factory interactions use the same rule. Player overlap uses the real 0.35 m capsule radius against the machine box; cell margins are not solid. The debug ring is 2 m. Preview and worker execution share the validator.

Toolbar data is an optional additive `factory-1` field. Known pre-toolbar saves default empty slots on detached data while preserving machines/native state. Unknown/tool entries and invalid slot counts/indices are rejected. Existing binding profiles gain missing toolbar actions while preserving custom/unbound controls. Inventory slot selection stays stable across unrelated simulation publications.
