# Scrapworks protagonist: MPFB version 1

Created 10 October 2026 in Blender 5.2.2 LTS with the installed MPFB 2.0.17 extension, through the official Blender MCP server.

The body was generated by MPFB. Eyes, eyebrows, eyelashes, teeth, tongue, ponytail, top, trousers and boots were attached and fitted by MPFB. The game-engine rig and its skin weights were also generated by MPFB. No character geometry from the earlier procedural prototype is included.

## Deliverables

- [Editable Blender project](protagonist-mpfb-v1.blend): the MPFB body retains its macro shape keys, asset associations and rig. Character textures are packed. Review cameras and lights are included in a separate collection.
- [Rigged GLB](protagonist-mpfb-v1.glb): 10 meshes, 195,504 triangles, 10 materials, 9 embedded texture images and one 53-joint skin. The studio is excluded. No animations are included.
- [MPFB preset](protagonist-mpfb-v1-preset.json): saves body settings, outfit, body parts, rig and MPFB material variants.
- [Front preview](preview-front.png), [three-quarter preview](preview-three-quarter.png), [back preview](preview-back.png) and [face preview](preview-face.png): rendered from the actual Blender model.
- [GLB roundtrip preview](preview-glb-roundtrip.png): rendered after importing the exported GLB into Blender.
- [Local MPFB asset library](mpfb-library/): source mesh, fitting and material files for the selected assets, with the original authorship and license comments retained.

## Appearance and MPFB assets

The character uses natural young-adult female proportions and is approximately 1.64 m tall including hair and boots. The native MPFB A-pose is retained.

| Component | MPFB asset | Treatment |
| --- | --- | --- |
| Body | MPFB human generator | Female, young-adult age setting, moderate muscle |
| Skin | young_caucasian_female | MPFB GameEngine material and authored texture |
| Eyes | high-poly | Brown eye material |
| Eyebrows and lashes | eyebrow001, eyelashes01 | Authored alpha textures |
| Hair | ponytail01 | Brown textured ponytail; softer specular highlights |
| Top | toigo_camisole_top, Margaret Toigo | Plain cream MPFB material variant |
| Trousers | cortu_cargo_pants, Cortu | Orange MPFB material variant; softened authored normal map |
| Boots | toigo_ankle_boots_male, Margaret Toigo | Charcoal MPFB material variant; softened authored normal map |
| Mouth parts | teeth_base, tongue01 | Authored MPFB assets and textures |
| Rig | game_engine | 53 bones; MPFB fitting and skin weights |

The lowered jumpsuit, tied sleeves, navy knee panels and swept fringe from the concept are replaced by available MPFB clothes and hair. The cream/orange/charcoal palette is retained. Clothing material variants intentionally replace the original patterned diffuse textures with plain colours.

## Editing and recreating

Open the `.blend` for the complete editable model. Select **Protagonist MPFB body** to use MPFB body settings and refitting. The rig is **Protagonist MPFB game rig**. Viewport overlays were hidden for the preview; enable them to see and select bones.

The file currently points MPFB's secondary asset root to this folder's `mpfb-library`. If the project is moved, update **MPFB → Apply assets → Library settings → second root** to the new absolute path of that directory. Packed textures remain available in the `.blend` without configuring the library; the library is needed for asset replacement, refitting and loading the preset.

The reproducible scripts are in [tools/art](../../../../../tools/art/): `build-protagonist-mpfb.py`, `stage-protagonist-mpfb.py`, `finish-protagonist-mpfb.py`, `export-protagonist-mpfb.py` and `render-protagonist-mpfb.py`. Build in a Blender session without an existing **Scrapworks - MPFB Protagonist v1** scene. The build script preserves other scenes. Material finishing is stored in the `.blend`; run the finish script when recreating solely from the preset.

## Validation

The exported GLB was reimported into Blender and rendered. All 10 character meshes have UVs and armature bindings. A lower-arm pose moved the exported geometry by approximately 9.4 cm and was then restored. The maximum difference between source and imported bounds was 0.90 mm. Blender's hidden bone-display Icosphere was excluded from the character mesh count.

See [build report](build-report.json), [Blender validation](blender-validation.json), [GLB inspection](glb-inspection.json), [roundtrip validation](roundtrip-validation.json) and [export report](export-report.json). This validates the model and its exported rig; game runtime integration and animation are outside this asset experiment.
