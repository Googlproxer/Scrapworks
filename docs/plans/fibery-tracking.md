## Relations and editing

Projects own milestones and tasks; each roadmap task also belongs to its milestone. The Fibery authoring/setup task is project-level. The initial import recorded ten milestone prerequisite links and 22 task dependency links; later milestone reviews refine those dependencies. The roadmap links describe ordering; they do not invent dates or imply that integration housekeeping erased completed simulation work.

**Unfinished Dependencies** counts incomplete prerequisite tasks. **Completed Tasks** and **Open Tasks** are live milestone formulas. These count work packages, not weighted percentages, and do not automatically change milestone status. **Current Focus** selects the immediate work view.

Relevant design/implementation tasks have 98 live links to the [catalogue](../design/balance/README.md) through Technologies, Recipes and Items (9 November readback). Catalogue records expose the inverse **Delivery Tasks** relation. These links connect design content to implementation work without treating a draft technology as completed gameplay.

Update workflow state as work is demonstrated, and keep acceptance criteria and dependency links current. A checked text checklist and the task workflow are separate fields: update the workflow deliberately when the scoped task is complete. Use the milestone description's completion criteria before closing a milestone.
