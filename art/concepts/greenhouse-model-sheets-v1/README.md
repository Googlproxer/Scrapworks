## Notes
- These sheets were generated from the supplied Greenhouse five-stage concept sheet.
- The Mixed-Output Recycler model sheet was used as the layout template.
- Minor inconsistencies may remain in exact proportions, annotation wording, and orthographic fidelity, so a quick visual pass before committing is recommended.
