# Scrapworks UI kit v1

Style revision 11, 11 November 2026. Reusable sources based on the user-accepted [screen concepts](../../concepts/2026-11-10/redesigns/), especially the [Field Kit](../../concepts/2026-11-10/redesigns/01-field-kit.png) and pause/save concept. The kit includes rotated title plates, coral repairs, reinforced patterned shells, a dimensional crank, cream inset text fields, steel dropdowns and continuous chamfered progress tracks. The decorated dialog now uses an independent inset fill, with transparent edge cutouts and reflected lower/right tiles. Matched inner corner faces close the backdrop seams while preserving the outer cutouts. The revised kit remains for user review.

The [UI kit guide](../../../../docs/art/ui-kit.md) owns the visual tokens, component roles, nine-slice metrics and responsive behaviour. The [Art Document](../../../../docs/art/README.md) owns the game's painted finish. These geometric source pieces preserve the concept's construction; they do not yet reproduce all of its painted character or select a final display font.

The [transparent dialog export](previews/dialog-transparent.png) preserves actual alpha around the decorated edges. The lower/right edge sources are reflected derivatives of the horizontal/vertical tile sources, with their transforms recorded in provenance.

Open the two HTML files in a browser; the saved bundle and relative assets require no server, network service or game startup. The component board remains a visual reference. In the responsive page, drag the crank around its centre in either direction, or focus it and use the arrow keys. Space/Enter turns a quarter-turn; Home resets charge. The local counter starts at 24/60 seconds, reaches full from empty in five turns, and does not drain while idle. Other buttons do not save, craft or close a real dialog. On compact windows, select MiniFab to reach the crank.

The [shared UI sprites](../../sprites/v1/README.md) now appear in twenty occupied inventory slots, the recipe result and ingredients, and the MiniFab heading/completed-result preview. Hover a slot for its item name; equivalent item names remain available to screen readers. Select any of the 27 current handcraft recipes and change the batch size to compare art and quantities. Ingredient space is reserved for four inputs, keeping the action controls anchored as recipes change. The preview reads the existing catalogue without issuing gameplay commands.

See the [inventory/crafting screenshot](previews/sprites-inventory-crafting.png), [medium layout](previews/sprites-medium.png), and [compact crafting view](previews/sprites-compact-crafting.png).

Rebuild after editing either TypeScript controller:

```powershell
node tools/art/build-ui-kit-demo.ts
```

The [builder](../../../../tools/art/build-ui-kit-demo.ts) runs the [strict demo type check](tsconfig.json), then bundles with the repository's existing Vite and RxJS dependencies. The emitted classic IIFEs avoid module-import restrictions on `file://` pages; their JavaScript is generated browser compatibility output, not the authoring source. Keep both bundles and the shared RxJS licence beside the HTML. No new package or runtime game dependency was added.

The twenty-six SVG files are original project-authored artwork created by Codex for this kit. They reference the existing Scrapworks logo and generated screen concepts stylistically, with no external art or font downloads. The transparent PNG pieces are raster renders of those vectors, not cutouts from the image concepts. The original PNG concepts and their exact image-generation prompts remain in [the dated concept folder](../../concepts/2026-11-10/). Display text in the proof uses local Arial Black / Segoe UI Black fallbacks; body copy uses the existing local sans stack.

The [crank detail](previews/crank-detail.png) shows its three registered artwork layers. Housing, arm and grip share a 256×256 canvas and a centre pivot at 128,128. In the interactive reference, the arm and grip rotate together while the four housing bolts remain fixed. A stationary outer `.crank-caster` applies the cast shadow after rotation, keeping its down-right light direction fixed; the moving SVGs retain material bevels but no baked cast-shadow offsets. See the [four-angle preview](previews/crank-shadow-angles.png). Pointer capture, centre dead zone, discontinuity rejection, blur/cancel/resize release and bounded charge are part of the local demo. This does not connect to production winding, simulation or saves.

Keep all source pieces here. Future runtime derivatives belong in `public/assets/` with their preparation record. Do not bake labels into exported surfaces. A full dialog PNG is a reference, not a scalable runtime asset. This delivery changes no production Angular templates, styles, simulation, input handling or CI workflows.
